Le but de ce site est de diffuser le Musée Gabriel sur le web;

Il comporte 4 pages: l'accueil, le programme saisonnier, 
comment trouver le musée, et comment candidater aux expositions saisonnières.

Pas besoin de s'inscrire pour y accéder, tout le contenu est disponible au public.

Navigation entre les pages: 

    menu burger et boutons href.

Déploiement:

    L'application est déployée sur LWS: museegabriel.com

    L'interface LWS pour mettre à jour l'application est simple et claire,
    mais présente des inconvénients.

    Il suffit de télécharger les fichiers nouveaux ou modifiés.
    La nouvelle version des fichiers écrase la version précédente.
    Il n'est pas possible de télécharger des dossiers, ceux-ci doivent être créés
    par avance sur le gestionnaire LWS.

    Pour ces raisons, il est primodial d'assurer un bon archivage sur git avant 
    tou déploiement sur LWS. La structure des dossiers doit être identique 
    sur les 2 plateformes, ceci est un contrôle manuel.

Structuration des fichiers:

    Dernière amélioration de l'application, le projet a été re-structuré dans son ensemble
    afin de permettre une maintenance plus efficace.
